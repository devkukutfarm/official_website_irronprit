## 1. Project Overview

IRRONPRIT Fitness is a gym brand based in Baruipur, West Bengal. This document defines the full product requirement — from a public-facing SEO website through a multi-branch management backend to a future e-commerce layer.

| Phase | Deliverable | Status |
|-------|-------------|--------|
| 1 | Official Website (Next.js + Tailwind) | **In Progress** |
| 2 | Backend REST API (ASP.NET) + Admin Panel (React.js) | Planned |
| 3 | E-Commerce Store (integrated) | Planned |

---

## 2. Tech Stack

| Layer | Technology | Notes |
|-------|-----------|-------|
| Official Website | Next.js 16+, Tailwind CSS v4 | App Router, SSG/ISR for SEO |
| Admin Panel | React.js 18+, Tailwind CSS v4 | SPA, communicates via REST |
| Backend / API | ASP.NET Core 8 (Web API) | REST, JWT auth, role-based |

| Hosting (Web) | Vercel | Official website |

| Hosting (Admin) | Vercel / Netlify | React admin SPA |

## 3. User Roles & Access Levels

| Role | Description | Portal |
|------|-------------|--------|
| **SuperAdmin** | Full system control, all branches | Admin Panel |

## 5. Phase 2 — Backend (ASP.NET) & Admin Panel (React.js)

### 5.1 Backend — ASP.NET Core Web API

#### 5.1.1 Authentication & Authorization

- JWT Bearer tokens, refresh token rotation
- ASP.NET Identity for user management
- Roles: `SuperAdmin`, `Admin`, `Trainer`, `Client`
- `[Authorize(Roles = "...")]` on all protected endpoints
- Password reset via email (SMTP / SendGrid)

#### 5.1.2 Branch Management

| Feature | Description |
|---------|-------------|
| Create Branch | Name, address, phone, Google Maps URL, operating hours, cover photo |
| Edit / Deactivate Branch | Soft delete (IsActive flag) |
| Branch-level config | Independent packages, trainers, classes, gallery |
| Multi-branch Admin | Admin can be assigned to one or many branches |

#### 5.1.3 Package Management (Per Branch)

| Feature | Description |
|---------|-------------|
| CRUD Packages | Plan name, duration, price, strike price, features list, is-featured flag |
| Enroll Client | Assign client to a plan + branch + start/end date |
| Membership Status | Active, Expired, Paused |
| Renewal Reminders | Trigger reminder X days before expiry (email/WhatsApp) |
| Payment Tracking | Record payment for each membership (cash / online) |

#### 5.1.4 Trainer Management (Per Branch)

| Feature | Description |
|---------|-------------|
| CRUD Trainer | Name, photo, bio, certifications, specializations, assigned branch/es |
| Trainer Login | Separate portal view restricted to their assigned clients |
| Salary Management | Monthly salary record, paid/unpaid, remarks |
| Attendance Tracking | Daily clock-in / clock-out, present/absent/half-day |
| Leave Management | Leave requests, approval by Admin |
| Client Assignment | Assign specific clients to a trainer (for PT) |

#### 5.1.5 Class Management (Per Branch)

| Feature | Description |
|---------|-------------|
| CRUD Classes | Name, description, schedule (days + time), trainer, capacity, photo |
| Class Attendance | Mark members who attended a class session |
| Class Categories | Strength, Cardio, HIIT, Yoga, Zumba, Personal Training |

#### 5.1.6 Client Management

| Feature | Description |
|---------|-------------|
| Client Profile | Name, photo, DOB, gender, phone, emergency contact, health notes |
| Membership | Current plan, branch, trainer, start/end date |
| Payment History | All payments made, receipts |
| Progress Tracking | Weight, body fat %, measurements logged over time |
| Goal Tracking | Goal set by trainer, milestone updates |
| Resource Access | Food charts, workout PDFs shared by trainer |
| Attendance | Gym visit log |

#### 5.1.7 Enquiry Form Management

| Feature | Description |
|---------|-------------|
| Receive Enquiries | Name, phone, interest (plan/class/PT), message, branch |
| Enquiry Status | New → Contacted → Converted / Closed |
| Assign to Admin | Branch admin sees their branch enquiries |
| WhatsApp Follow-up | Click-to-WhatsApp from enquiry detail |

#### 5.1.8 Gallery / CMS Management

| Feature | Description |
|---------|-------------|
| Upload Images/Videos | Per branch or global |
| Categorize | Gym interior, Events, Member transformations, Equipment |
| Publish/Unpublish | Control what shows on official website |
| Official Website Sync | Official website `/gallery` page fetches from API |

#### 5.1.9 Homepage / Section CMS (Phase 2 upgrade)

Allows admin to edit official website content without code changes:
- Hero text (heading, subheading, CTA labels)
- Why IRRONPRIT bullets
- Stats numbers (years, trainers, members)
- Member reviews / testimonials
- Announcements / promo banner text

### 5.2 Admin Panel — React.js SPA

#### 5.2.1 Authentication Flow

- Login page (email + password) → JWT stored in `httpOnly` cookie or secure `localStorage`
- Role-based redirect: SuperAdmin → full dashboard, Admin → branch dashboard, Trainer → trainer view, Client → client portal

- Session expiry + refresh

#### 5.2.3 Admin (Branch-level) Dashboard

| Section | Features |

| Packages | Create/edit branch packages (visible on official website) |

#### 5.2.4 Trainer Portal

| Section | Features |
|---------|---------|

| Client Profile | Full profile, goal, measurements history |
| Log Progress | Add weight/measurement entry for a client |
| Goal Management | Set goal, update milestones |
| Resources | Upload food chart PDF, workout plan — assign to specific client |
| Attendance | View own attendance record |
| Salary | View salary slips |

#### 5.2.5 Client Portal

| Section | Features |
|---------|---------|
| My Dashboard | Current membership status, days remaining, trainer name |
| Progress Tracker | Weight & body measurement chart over time |
| Goal Tracker | Current goal, milestone checklist |
| Resources | Download food chart, workout plan shared by trainer |
| Fitness Calculators | BMI, BMR, Calorie Target, Body Fat %, Ideal Weight, Macro split |
| Attendance Log | My gym visit history |
| Membership | Current plan, payment history, renewal reminder |
| Enquiry / Support | Contact trainer or admin via message |

#### 5.2.6 Fitness Calculators (Client Portal)

| Calculator | Inputs | Output |
|-----------|--------|--------|
| BMI | Height, Weight | BMI value + category |
| BMR | Age, Gender, Height, Weight | Calories/day at rest |
| TDEE | BMR + Activity level | Total daily energy expenditure |

| Water Intake | Weight, activity, climate | Daily water target (litres) |

## 7. Backend API Contracts (REST)

Base URL: `https://api.ironprit.com/api/v1`

### Auth

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/auth/login` | Returns JWT + refresh token |
| POST | `/auth/refresh` | Rotate refresh token |
| POST | `/auth/logout` | Revoke refresh token |
| POST | `/auth/forgot-password` | Send reset email |
| POST | `/auth/reset-password` | Confirm reset |

### Branches

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/branches` | List all branches (public) |
| GET | `/branches/{id}` | Branch detail (public) |
| POST | `/branches` | Create branch (SuperAdmin) |
| PUT | `/branches/{id}` | Update branch (Admin+) |
| DELETE | `/branches/{id}` | Soft delete (SuperAdmin) |

### Packages

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/branches/{branchId}/packages` | List packages for branch (public) |
| POST | `/branches/{branchId}/packages` | Create package (Admin+) |
| PUT | `/packages/{id}` | Update package (Admin+) |
| DELETE | `/packages/{id}` | Delete package (Admin+) |

### Trainers

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/branches/{branchId}/trainers` | Public trainer list |
| GET | `/trainers/{id}` | Trainer detail (public) |
| POST | `/trainers` | Create trainer (Admin+) |
| PUT | `/trainers/{id}` | Update trainer (Admin+) |
| POST | `/trainers/{id}/attendance` | Log attendance (Admin) |
| GET | `/trainers/{id}/salary` | Salary records (Admin/Trainer) |

### Classes

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/branches/{branchId}/classes` | Class list (public) |
| GET | `/classes/{id}` | Class detail (public) |
| POST | `/classes` | Create class (Admin+) |
| PUT | `/classes/{id}` | Update class (Admin+) |

### Clients / Members

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/clients` | List clients (Admin+) |
| GET | `/clients/{id}` | Client detail (Admin/Trainer/Client-self) |
| POST | `/clients` | Register client (Admin+) |
| PUT | `/clients/{id}` | Update client (Admin+) |
| GET | `/clients/{id}/progress` | Progress log |
| POST | `/clients/{id}/progress` | Add progress entry (Trainer) |
| GET | `/clients/{id}/resources` | Resources shared by trainer |
| POST | `/clients/{id}/resources` | Upload resource (Trainer) |

### Memberships

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/memberships` | Enroll client in a plan |
| PUT | `/memberships/{id}` | Renew / update membership |
| POST | `/memberships/{id}/payment` | Record payment |
| GET | `/memberships/expiring` | Upcoming renewals (Admin) |

### Enquiries

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/enquiries` | Submit enquiry (public — official website form) |
| GET | `/enquiries` | List enquiries (Admin+) |
| PUT | `/enquiries/{id}` | Update status (Admin+) |

### Gallery

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/gallery` | Public gallery (official website) |
| POST | `/gallery` | Upload image (Admin+) |
| DELETE | `/gallery/{id}` | Remove image (Admin+) |

### Calculators

All calculators are **client-side only** — no API required. Logic runs in React.

## 8. Database Entities

### Core Tables

```
Branch

User (ASP.NET Identity)

  - Id, ClientId, PackageId, BranchId, StartDate, EndDate, Status (Active/Expired/Paused)

Payment

Class
  - Id, BranchId, Name, Description, Category, Schedule (days + time), TrainerId, Capacity, Photo

ClassAttendance
  - Id, ClassId, ClientId, Date

Enquiry
  - Id, BranchId, Name, Phone, Email, Interest, Message, Status, CreatedAt, AssignedTo

ProgressEntry
  - Id, ClientId, Date, Weight, BodyFat, Chest, Waist, Hips, Notes

Goal
  - Id, ClientId, TrainerId, Title, Description, TargetDate, Milestones[], Status

Resource
  - Id, ClientId, TrainerId, Title, FileUrl, Type (FoodChart/WorkoutPlan/Other), CreatedAt

GalleryItem
  - Id, BranchId, FileUrl, Caption, Category, IsPublished, CreatedAt

TrainerAttendance
  - Id, TrainerId, Date, Status (Present/Absent/HalfDay), ClockIn, ClockOut

TrainerSalary
  - Id, TrainerId, Month, Year, Amount, PaidDate, Status (Paid/Unpaid), Remarks

Announcement
  - Id, BranchId, Title, Body, IsActive, CreatedAt, ExpiresAt
```

## 9. Non-Functional Requirements

| Requirement | Target |
|-------------|--------|
| Page Load (official website) | < 2.5 s LCP on 4G |
| Core Web Vitals | LCP < 2.5 s, CLS < 0.1, FID < 100 ms |
| API Response Time | < 300 ms for list endpoints under normal load |
| Uptime | 99.5% (official website + API) |
| Mobile Responsiveness | Fully responsive — 320 px to 2560 px |
| SEO | Google PageSpeed ≥ 90 (mobile + desktop) |
| Security | HTTPS everywhere, OWASP Top 10 mitigated, parameterised queries, JWT expiry 15 min |
| Auth Token Expiry | JWT: 15 min access, 7-day refresh (rotating) |
| Image Optimization | next/image for website, compressed uploads ≤ 2 MB for admin |
| Backups | Daily DB backup, 30-day retention |
| CORS | API allows only official website + admin panel origins |
| Rate Limiting | Public endpoints: 60 req/min per IP |
| Audit Log | All Admin/SuperAdmin write actions logged with userId + timestamp |

## 10. Out of Scope

The following are explicitly **not** in scope for any current phase unless stated:

- Native mobile apps (iOS / Android)
- Live video / class streaming
- Third-party fitness device integrations (Fitbit, Apple Watch)
- Multi-language / multi-currency support
- Franchise management beyond branch-level admin
- Custom email server (use SendGrid or similar relay)
- Automated AI-generated workout plans
